Analytics Setup Guide

How to configure tracking for NoCode Launchpad

Google Analytics 4 Setup

Step 1: Create GA4 Property

  1. Go to Google Analytics
  2. Click Admin → Create Property
  3. Enter property name: "NoCode Launchpad"
  4. Select timezone and currency
  5. Choose Web platform
  6. Enter website URL
  7. Get your Measurement ID (G-XXXXXXXXXX)

Step 2: Add to Jekyll

Update _config.yml:

google_analytics: "G-XXXXXXXXXX"  # Your real GA4 ID

Step 3: Verify Tracking

  1. Wait 24-48 hours for data to appear
  2. Check Realtime report
  3. Visit your site and verify pageview appears

Conversion Events

Track these important events:

Event Description Trigger
sign_up Email newsletter signup Form submission
affiliate_click Affiliate link click Click on Base44/Wix link
tutorial_complete Tutorial read completion Scroll to bottom

Google Search Console

Setup Steps

  1. Go to Search Console
  2. Add property (URL prefix or Domain)
  3. Verify via HTML tag or DNS
  4. Submit sitemap: https://chanw0w.github.io/nocode-launchpad/sitemap.xml

Key Metrics to Monitor

  • Clicks: Traffic from search
  • Impressions: Times shown in search
  • CTR: Click-through rate
  • Position: Average ranking

Affiliate Tracking

Monitor affiliate performance via Impact.com API:

cd ~/affiliate-marketing/playwright-scripts
npm run api-stats

Key Metrics

  • Clicks per program
  • Conversions
  • Revenue
  • EPC (Earnings per click)

Email Analytics (Brevo)

Track in Brevo dashboard:

  • Open rate: Target >25%
  • Click rate: Target >5%
  • Subscribers: Growth over time
  • Unsubscribe rate: Keep <1%

Social Media Analytics (Buffer)

Track in Buffer dashboard:

  • Impressions: Post reach
  • Engagement: Likes, comments, shares
  • Link clicks: Traffic to blog
  • Follower growth: Audience building

Weekly Review Checklist

  • □ Check GA4 traffic report
  • □ Review Search Console performance
  • □ Run npm run api-stats for affiliate data
  • □ Check Brevo email metrics
  • □ Review Buffer social metrics
  • □ Document insights and adjustments
